# Pins for the SPEI-3 producer (.github/workflows/spei3_refresh.yml) and
# NOTHING else. Deliberately its own file rather than an entry in
# constraints-ci.txt or a pyproject extra: cdsapi is a credentialled client
# for one external service, and the resolution path must never be able to
# import it. The rulebook's contract is that a Resolver Update reads a
# committed CSV; adding a scientific stack to the pipeline's dependency set
# to produce that CSV would give up the only thing the arrangement buys.
#
# The four analysis pins MATCH constraints-ci.txt on purpose. The reduce
# stage runs here and its tests run under the resolver suite, so a version
# skew between the two would mean CI green on a reduction production never
# performs. Bump them together.
cdsapi==0.7.7
xarray==2025.12.0
netCDF4==1.7.4
numpy==2.4.6
shapely==2.1.2

# The reduce stage borrows the vendored boundary layer from
# resolver.hazard_resolution.geometry, so that it and the resolution path
# agree on where a country is rather than each having its own answer. Reading
# a module from that package executes the package's __init__, which imports
# the rulebook, which imports yaml. So a transitive need of a deliberate
# import, not a dependency of this producer's own code — and it is declared
# here rather than left to chance, because the run that found it had already
# spent nine minutes downloading a gigabyte and read 128 grids before the
# import fired. Guarded by
# test_the_requirements_declare_everything_the_geometry_import_pulls_in.
PyYAML==6.0.3
