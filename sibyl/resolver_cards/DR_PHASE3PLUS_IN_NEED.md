How this question resolves (checked against pythia/tools/compute_resolutions.py):
- Source: the FEWS NET or IPC CURRENT-SITUATION figure for people in IPC Phase 3 or worse, for the month. Projections never resolve it.
- The figure changes only when a new analysis is published; between analyses the same number carries through the months it covers.
- A month with no current-situation figure stays unresolved; it is never scored as zero.
- A change in the area analysed (a region added or dropped, a new population base) moves the number with no change on the ground. Check what the latest analysis covers.
